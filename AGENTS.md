## System Tiers & VIP Grade Alignment
- **VIP Level 0 (Unactivated)**: Newly registered users start at VIP Level 0 with an **Unactivated** status. They do not earn any passive dynamic yields, and the earnings ledger shows as locked/unactivated.
- **Earning Protocol Activation**: A user must activate their first active investment plan (such as Starter Level or VIP Levels) to transition from VIP Level 0 to an active earning state.
- **Daily Level Income Display**: The daily level earnings tracker in the Earnings tab is fully hidden/locked and displays an "Earning Protocol Unactivated" lockscreen if the user is VIP Level 0.
- **Settlement Timer**: The settlement countdown timer is locked/inactive for VIP Level 0 users and displays a "Locked" status. Once a plan is activated, the countdown clock unlocks and starts counting down.
